# Piper assets directory

Place Piper TTS model files (.onnx and .onnx.json) in this directory:
- `audio-service/assets/piper_ko.onnx` & `audio-service/assets/piper_ko.onnx.json`
- `audio-service/assets/piper_en.onnx` & `audio-service/assets/piper_en.onnx.json`
- `audio-service/assets/piper_ja.onnx` & `audio-service/assets/piper_ja.onnx.json`
or default model:
- `audio-service/assets/piper.onnx` & `audio-service/assets/piper.onnx.json`
