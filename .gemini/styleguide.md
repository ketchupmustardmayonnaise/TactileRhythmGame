# 코드 리뷰 언어 설정

- 모든 코드 리뷰 피드백과 코멘트는 반드시 **한국어**로 작성해주세요.
- 전문 용어는 가급적 원문을 병기하거나 한국어 개발 관례에 따라 작성해주세요.

# Rust 스타일 가이드

- **Rust 에디션:** 프로젝트는 **Rust 2024 Edition**을 기준으로 작성됩니다.
- **리뷰 기준:**
  - Rust 2024에서 도입된 최신 문법(예: `gen` blocks, 더욱 엄격해진 `impl Trait` 등)을 적극적으로 활용하도록 제안해주세요.
  - 구식(2018 또는 2021) 스타일의 코드가 보이면 2024 에디션 방식에 맞춰 수정을 권고해주세요.
