# 게임 애플릿

이 애플릿은 멀티라인 점자 디스플레이를 위한 간단한 게임입니다.

## 특징

- 점자 디스플레이를 활용한 간단한 게임 플레이

## 실행 방법

이 애플릿은 `multiline-braille-display` 프로젝트의 일부입니다. 프로젝트 루트 디렉토리에서 다음 명령을 사용하여 실행할 수 있습니다:

```bash
just run game
```

## 개발

이 애플릿은 Rust로 작성되었으며, `multiline-braille-display` SDK를 사용합니다. `applets/game` 디렉토리에서 코드를 찾을 수 있습니다.
