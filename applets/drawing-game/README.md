# Drawing Game Applet

점자 디스플레이를 위한 픽셀 드로잉 애플리케이션입니다. 넓은 캔버스 위에서 커서를 이동하며 그림을 그리고, 브러시 크기를 조절하거나 물리 기반의 이동 모드를 즐길 수 있습니다.

## 주요 기능

- **광활한 캔버스**: 1000x1000 크기의 비트맵 캔버스를 지원하며, 뷰포트 시스템을 통해 화면을 이동합니다.
- **다양한 그리기 도구**: 그리기(Draw), 지우기(Erase) 모드 및 브러시 크기 조절 기능을 제공합니다.
- **물리 엔진 이동**:
  - **Standard Mode**: 즉각적인 반응의 정밀한 이동.
  - **Inertia Mode**: 가속도와 마찰력이 적용된 부드러운 이동.
- **최적화**: 비트 패킹(Bit-packing)과 브레젠험 직선 알고리즘(Bresenham's line algorithm)을 사용하여 메모리와 성능을 최적화했습니다.

## 조작 방법 (Controls)

### 기본 조작

- **방향키 (Up/Down/Left/Right)**: 커서 이동
- **Home**: 일반(Normal) 모드로 즉시 복귀 (커서만 이동하고 그리지 않음)

### 모드 변경

- **Center + End**: 편집 모드 순환 (`Normal` → `Draw` → `Erase`)
- **Center + Home**: 브러시 크기 변경 모드 진입

### 이동 모드 설정 (Center 누른 상태에서)

- **Center + Left**: 표준 이동 모드 (Standard Mode) - 정밀 조작
- **Center + Right**: 관성 이동 모드 (Inertia Mode) - 가속도 적용

### 그리기 / 지우기

- **Center (누름/유지)**: 현재 모드(`Draw`/`Erase`)에 따라 픽셀을 칠하거나 지움.
  - 빠르게 이동하며 그릴 때도 선이 끊기지 않도록 자동으로 연결됩니다.

### 브러시 크기 변경 모드

- **Up / Down**: 브러시 크기(반지름) 조절
- **Center**: 크기 결정 및 이전 모드로 복귀
- **End**: 취소 및 이전 모드로 복귀

## 기술적 특징

### 렌더링 및 메모리

- **BitPixelBuffer**: `u8` 벡터를 비트 단위로 사용하여 메모리 사용량을 1/8로 줄였습니다.
- **Viewport Culling**: 전체 캔버스 중 화면에 보이는 영역만 계산하여 렌더링 성능을 확보했습니다.

### 입력 처리

- **키 버퍼링**: 빠른 입력 시 키가 씹히지 않도록 스택 기반의 키 버퍼를 사용합니다.
- **조합 키(Chord) 처리**: `Center` 키와 다른 키의 조합을 상태 머신으로 처리하여 오작동을 방지합니다.

## 설정

`config.rs` 파일에서 캔버스 크기, 물리 연산 계수(마찰력, 가속도), 렌더링 옵션 등을 수정할 수 있습니다.
